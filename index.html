연습 과제

매뉴얼 순서대로 9가지를 직접 해보세요.

    교육 담당자용

    이 화면은 연습용 모형입니다. 실제 결제·취소는 일어나지 않으니 신입 알바에게 자유롭게 눌러보게 해도 됩니다. 현장 상품 구성은 포스에 등록된 실제 목록을 따릅니다.

    하루 운영 순서

    1. 포스 전원을 켜고 바탕화면에서 플러스 포스를 터치합니다.
    2. 판매관리에 들어가 개점등록을 합니다. 매일 오픈 때 한 번.
    3. 상품을 담고 옵션까지 고른 뒤 결제합니다.
    4. 취소·반품 건은 영수증관리에서 처리합니다.
    5. 영업이 끝나면 영업관리 → 마감정산으로 그날 매출을 확정합니다.
    6. 카드단말기에서 마감정산서가 자동 출력되면 보관합니다.
    7. 시스템종료로 포스를 끕니다.

    메인 화면 버튼

    판매관리상품 등록과 결제. 영업 중 가장 많이 쓰는 화면입니다.
    영업관리개점(준비금 등록), 마감정산, 마감취소.
    매출현황분류별·상품별·시간대별 매출 조회.
    자료수신관리자 웹에서 바꾼 상품 정보를 포스로 내려받습니다.
    환경설정 / 시스템종료장비 설정과 포스 끄기.
    관리자 웹(OKPOS)에서 상품을 추가하거나 수정했다면 자료수신을 눌러야 포스 화면에 반영됩니다.

    결제 수단

    신용카드일반 카드 결제. 리더기에 금액이 뜨면 손님에게 보여 주고 카드를 꽂거나 대도록 안내합니다.
    모바일결제네이버페이·카카오페이·제로페이 등 바코드/QR. 알리페이와 위챗페이는 받을 수 없습니다.
    현금현금 없는 매장입니다. 카드 결제만 가능하다고 정중히 안내하세요. 계좌이체도 받지 않습니다.
    카드를 꽂았는데 반응이 없으면 취소를 누르고 처음부터 다시 진행합니다. 같은 건을 두 번 승인 요청하면 이중 결제됩니다.

    반품과 교환

    • 결제 전이면 선택 취소 또는 전체 취소, 결제 후면 영수증관리 → 반품입니다.
    • 반품과 교환은 결제했던 카드로만 처리합니다.
    • 반품 전에 제품 상태를 반드시 확인합니다.
    • 교환은 취소 후 재결제해야 재고와 매출에 제대로 반영됩니다.
    • 목록의 상태가 반품원거래(플러스)와 반품매출(마이너스) 두 줄로 남으면 정상 처리된 것입니다.

    마감조가 꼭 지킬 것

    • 마감 전에 화면의 실매출액과 실제 카드 승인액이 맞는지 대조합니다. 차이가 나면 마감하지 말고 취소·반품 내역부터 확인하세요.
    • 마감정산서를 출력해 보관합니다.
    • 포스 마감까지 끝낸 뒤에 포스를 종료합니다.

    증상별 조치

    결제 버튼을 눌러도 반응이 없다화면 상단 통신상태를 확인하고 랜선과 와이파이를 점검한 뒤 프로그램 재시작.
    카드가 안 읽힌다IC칩을 끝까지 꽂았는지 확인 → 뒷면 마그네틱으로 긁기 → 그래도 안 되면 포스 프로그램을 재시작하고 다시 결제.
    영수증이 안 나온다용지 확인(빨간 줄이 보이면 교체) → 용지함 덮개가 완전히 닫혔는지 확인 → 영수증관리에서 재출력.
    금액을 잘못 받았다 (결제 전)선택 취소 또는 전체 취소 후 다시 입력.
    금액을 잘못 받았다 (결제 후)영수증관리에서 해당 영수증을 선택해 반품하고 다시 결제.
    화면이 멈췄다시스템종료에서 프로그램 재시작. 매출 자료는 서버에 저장되어 사라지지 않습니다.
